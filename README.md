## 🚀 Features (English )

- **Smart Dashboard:** Real-time statistics, current balance, and interactive charts (Chart.js) for cash flow.
- **Daily Operations Management:** Add/Edit daily records with specific fields (Morning Shift, Evening Shift, Bank Feeds) and dynamic multiple expenses per day.
- **Automated Calculations:** Calculates net balance instantly without manual math, ensuring 100% accuracy.
- **Monthly Reports:** Excel-like report generation, automated calculation of the previous month's closing balance as the current month's opening balance, with a print-ready view.
- **Secure Authentication:** Username/Password login system with protected routes.
- **Dynamic Settings:** Update the system name globally and securely change the admin password.
- **Responsive UI:** Built with Tailwind CSS, fully responsive and RTL-optimized for Arabic users.

## ✨ المميزات (عربي)

- **لوحة تحكم ذكية:** إحصائيات حية، عرض الرصيد الحالي للصندوق، ورسوم بيانية تفاعلية (Chart.js) لحركة الأموال.
- **نظام إدارة العمليات اليومية:** إضافة وتعديل حركات اليوم (شفت صباحي، مسائي، تغذية البنك) مع إمكانية إضافة مصروفات متعددة لليوم الواحد بشكل ديناميكي.
- **حسابات مؤتمتة:** حساب الصافي اليومي والرصيد الإجمالي تلقائياً لتجنب الأخطاء البشرية وضمان التطابق المالي.
- **تقارير شهرية دقيقة:** استخراج تقارير دقيقة وحساب "رصيد بداية المدة" تلقائياً من الأشهر السابقة، مع واجهة جاهزة للطباعة.
- **حماية وأمان:** نظام تسجيل دخول آمن يعتمد على (اسم المستخدم وكلمة المرور) مع حماية جميع المسارات.
- **إعدادات مرنة:** إمكانية تغيير اسم النظام ديناميكياً لينعكس على كافة الصفحات، مع تغيير كلمة المرور بأمان.
- **واجهة عصرية:** تصميم متجاوب 100% بالاعتماد على Tailwind CSS، وداعم بالكامل للغة العربية (RTL).
